# Moonbase Control: Final project

Zadanie z modułu Angular. Repozytorium zawiera kod startowy aplikacji Moonbase Control dla tej lekcji.

## Zadanie

Przeprowadź samodzielną rozbudowę aplikacji.

Wybierz i zaimplementuj jedną dodatkową funkcjonalność, wykorzystując wiedzę zdobytą podczas całego modułu, np.:

- wyszukiwanie misji,
- filtrowanie po statusie,
- nowy widok szczegółów,
- dodatkowy formularz,
- nowe źródło danych z API.

To zadanie pełni rolę mini-projektu końcowego i pozwala połączyć wszystkie poznane zagadnienia w jedną spójną funkcjonalność.

💡 W opisie Pull Requesta opisz wybraną funkcjonalność i sposób jej sprawdzenia w aplikacji.

## Jak zacząć

1. Zrób fork tego repozytorium na swoje konto GitHub.
2. Sklonuj swój fork na komputer.
3. Zainstaluj zależności: `npm install`.
4. Uruchom aplikację: `npm start`.
5. Jeśli zadanie korzysta z danych z API, uruchom w drugim terminalu mock API: `npm run api`.

## Jak oddać zadanie

1. Zapisz zmiany w commicie i wypchnij je do swojego forka.
2. Otwórz Pull Request z forka do repozytorium `mate-academy/angular_final-project`, do brancha `main`.
3. Platforma uruchomi review Twojego Pull Requesta.
